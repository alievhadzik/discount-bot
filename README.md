# 🛍️ Мои скидки — Telegram-бот для поиска скидок

Telegram-бот, который помогает пользователям быстро находить актуальные скидки на интересующие их товары и категории.

## 📌 Как это работает

1. Пользователь открывает бота и выбирает интересующую категорию или товар
2. Бот показывает актуальные скидки по выбранной категории
3. Администратор бота добавляет и обновляет скидки через специальные команды

## ⚙️ Возможности

- 📂 Просмотр скидок по категориям (Одежда, Электроника, Красота, Дом и быт, Путешествия)
- 🔎 Удобная навигация через inline-кнопки
- 👤 Административная панель для добавления и удаления скидок
- 💾 Хранение данных в JSON-файлах

## 🛠️ Технологии

- **Python 3.13**
- **python-telegram-bot** — работа с Telegram Bot API
- **python-dotenv** — безопасное хранение токена бота
- Хостинг: **Railway** (работает 24/7)

## 🔐 Безопасность

Токен бота хранится в переменной окружения (`.env`) и не попадает в открытый код — файл `.env` исключён из репозитория через `.gitignore`.
